Tool 1 • Latency & Stability Monitor

Ping Checker Pro 2

Continuous multi-target ICMP latency graphing with 7-day timeline scrubbing, custom packet payload sizes (32B – 1472B MTU), keyboard shortcuts, and asynchronous audit logging.

Ping Checker Pro 2 - [Live Dashboard]
🌐
10-Host Concurrent Monitoring

Track up to 10 IP addresses or domain names simultaneously with distinct color-coded trendlines and individual host visibility toggles.

🕒
7-Day Timeline Scrubbing

Store up to 604,800 records in memory. Drag the full-width timeline slider left to enter ⏸ PAUSED mode and inspect historical spikes.

⌨️
Keyboard Precision Navigation

Nudge timeline point-by-point with Left/Right Arrow keys or hold Shift + Arrow for 10x fast rewind/forward.

📜
Asynchronous Audit Logging

Non-blocking background thread writes timestamped logs to ping_log.txt without UI lag. Features dual timestamps (History Since & Last Start).

Tool 2 • Subnet & Device Discovery

IP Scanner Pro

Fast multi-threaded network scanner that parses local subnets, resolves MAC addresses & IEEE OUI hardware vendors, detects open ports/services, and exports audit reports.

🔍
Subnet & IP Range Scanning

Auto-detects active local subnet ranges (e.g. 192.168.1.0/24, 192.168.88.1-254) or custom IP lists with high-speed parallel worker threads.

🏷️
MAC & Hardware Vendor Resolution

Uses Win32 SendARP API and ARP cache lookups to resolve MAC addresses and identify manufacturers (Apple, Cisco, Ubiquiti, Synology, Raspberry Pi, etc.).

🔌
Port & Service Fingerprinting

Scans common operational ports (HTTP, HTTPS, SSH, RDP, SMB, VNC, SNMP, Printer) and automatically categorizes active network hardware.

📋
Host Inspector & Reporting

Dedicated Host Inspector pane with quick remote shortcuts (HTTP, HTTPS, RDP, WOL, Deep Scan) and instant CSV/JSON/HTML report exports.

IP Scanner Pro - [Subnet & Asset Auditor]
Tool 3 • Fast & Resilient File Copier

DataCopier Pro

High-speed Windows data migration and synchronization engine combining raw FastCopy multi-threaded throughput with Roadkil's Unstoppable Copier fault-tolerant sector recovery.

DataCopier Pro - [Fast & Resilient Engine]
🚀
Ultra-Fast Multi-Threaded I/O

Configurable 1 MB to 16 MB chunked zero-GC memory streaming with up to 16 parallel worker threads to saturate NVMe, SSD, and gigabit NAS storage.

🕒
100-Nanosecond Timestamp Fidelity

Preserves exact Creation, Last Modified, and Last Access timestamps using Windows kernel32.SetFileTime, with deepest-first folder timestamp fixups.

🛡️
Unstoppable Damaged Sector Rescue

Gracefully recovers data from failing drives or bad sectors by switching to 4 KB sector reads and zero-fill padding readable fragments without aborting.

🔄
Sync Mirroring, Dry-Run & Safe Deletes

Supports Diff (newer only), Sync/Mirror, and Full Overwrite. Obsolete sync deletions route safely to the Windows Recycle Bin, with full Dry-Run simulation.
