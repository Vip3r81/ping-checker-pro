Multi-Target Engine

Monitor up to 10 IP addresses or domain names simultaneously. Each host receives a distinct color-coded trendline with individual visibility toggles.

🕒

7-Day History Scrubbing

Retain up to 604,800 records in memory. Drag the full-width timeline slider to rewind and inspect historical latency spikes over hours or days.

⏸️

Instant Auto-Pause & Jump

Moving the timeline slider left instantly freezes the graph in ⏸ PAUSED mode for deep analysis. Click ▶ JUMP TO LIVE to snap back to real-time tracking.

⌨️

Keyboard Precision Scrubbing

Use Left / Right Arrow keys to nudge history point-by-point, or hold Shift + Arrow for 10x fast rewind/forward. Includes smart input protection while typing.

🔎

Multi-Level Zoom Window

Switch between 1m, 5m, 10m, 30m, and 1h time windows at any time. Right-click anywhere on the canvas to instantly reset the vertical scale.

📜

Asynchronous Audit Logging

Non-blocking worker thread streams clean, timestamped logs to ping_log.txt without UI stutters. Features dual timestamp headers (History Since & Last Start).

Timeline Scrubbing Controls

Quickly navigate complex multi-day packet loss logs using keyboard shortcuts or mouse gestures without interrupting background ping collection.

🛡️
Administrator Privilege Required:
Sending raw ICMP socket packets on Windows requires Elevated Privileges. Always right-click and select "Run as Administrator".
